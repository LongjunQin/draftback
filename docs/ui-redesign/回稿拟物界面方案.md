# 回稿拟物界面方案

第五版,10 月 16 日。这一版只改了火漆印:去掉「回」字外面的圆圈。所有用到火漆印的图都换了。

已经定下来的:

- 方案 C:软皮手账。
- 封面颜色 6 种:青雾蓝(默认)、鼠尾草绿、薰衣草紫、浅金、星宇橙、深空黑。用户在设置里自己选。
- 图标上的火漆印放大,占图标的八成多。
- 火漆印不要圆圈,「回」字就是印面。

页面照着现在的 App 画。每个状态显示什么、按钮叫什么,都和现在一样。和现在不一样的地方只有下面 6 处。

## 这一版改了火漆印

你提的:「回」字外面那一圈圆没有意义,去掉。

![火漆印改前改后](images/C-seal.jpg)

- 「回」字的外框就是印的边。框里压下去,蜡从四边挤出来,鼓在外面。
- 圆圈原来是圆形印头压出来的边。在这里它不表示什么,还占地方。
- 去掉圆圈以后,「回」字放大到原来的约 1.4 倍。图标缩小以后也看得清。
- 图标、定稿按钮、定稿后压在标题旁的印,都换成了新印。

## 和现在不一样的地方

1. **手机加一个「设置」页。** 首页右上角的齿轮进入。里面有封面颜色、图标跟着封面换、外观、正文字号、iCloud 和版本。现在手机没有设置页,字号在「…」菜单里,那里也照样留着。
2. **Mac 的设置里加封面颜色。** 放在「外观」第一项,还有「程序坞图标跟着封面换」。外观的「浅色 / 深色」改叫「日间 / 夜读」,和手机一样。
3. **手机首页的大类。** 大类的标题放在一条浅色带上,和下面的稿子分开。右边是带字的「收起」「展开」按钮。这是你之前提的两条。
4. **Mac 定稿改成原地确认。** 现在 Mac 点「通过 · 定稿」会弹框。改成工具栏原地变成「确认定稿?」,再按一次火漆印才算定稿。手机已经是原地确认。
5. **定稿按钮是一枚火漆印。** 手机下栏写「盖章定稿」,Mac 工具栏写「通过 · 定稿」,旁边都是火漆印。
6. **手机定稿以后,** 正文标题旁边压一枚火漆印,写上日期。
