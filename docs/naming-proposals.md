## 1. 一个英文名走天下,还是中英各一个?

**建议:英文名是唯一的「身份」,中文名是中国区的「叫法」。两个都要,但不是翻译关系。**

- App Store 允许每个国家/地区商店显示不同的名字。中国区显示中文名,其他地区显示英文名,这是苹果官方支持的做法。
- 微信 / WeChat、飞书 / Lark、钉钉 / DingTalk 都是这么干的;Notion、Obsidian 则只有英文名,中国用户也照样叫。
- 包标识、域名、代码仓库、文件后缀这些永远只用英文名,所以英文名先定,中文名可以稍后、也可以不止一个候选。
- 中文名不要直译英文,要顺口、能望文生义;两个字最好,三个字也行。

## 2. 好名字的标准(按这个打分)

1. 一口气读得出来,听一遍会拼(避免字母缩写、避免 th / r 连读)。
2. 两个音节最好,三个可接受。
3. 能让人猜到「一轮一轮批、交给 AI 改」这个独特动作,而不只是「Markdown 阅读器」。
4. 中文名能单独站住,不靠英文解释。
5. 没被同类产品占用(选定后我去查 App Store、域名、商标)。

现在的「MDTurn」:第 3 条满分(Turn 抓住了轮次),第 1 条不及格(字母加单词,读法不统一,MD 在中文里还有脏字联想),第 4 条没有中文名。

## 3. 候选方案

每条格式:**英文名**(怎么读)/ **中文名** —— 含义;顾虑。

### 方案 A:Turnpage / 轮稿(原配的「翻篇」因中国区撞名改为「轮稿」)

- 读:turn-page,两个音节,都是小学词。
- 含义:保留了「Turn」的轮次意象,加上「页」说明是读文档的;中文「轮稿」= 一轮一轮改稿,中国区干净。
- 调研:App Store 两区都没有同名;但 turnpage.app 和 turnpage.com 都已被注册,只能用 .cn 或换个域名写法(如 turnpage.cc)。

### 方案 B:Draftback / 回稿

- 读:draft-back,两个音节。
- 含义:最直白——稿子交出去,改完回到你手上。中文「回稿」是编辑行业的现成说法(稿子回来了)。
- 调研:App Store 两区都没有同名或近似;draftback.app、draftback.cn、huigao.app 都可注册(draftback.com 已被注册)。唯一的已知同名是一个 Chrome 浏览器扩展(回放 Google 文档的编辑过程),不在 App Store,领域不同。

### 方案 C:Rally / 来回

- 读:ra-lly,两个音节,中文嘴也顺(「拉力」)。
- 含义:网球里的「对拉」——一来一回、越打越好,正是人批注、AI 改稿的节奏。中文「来回」口语、好记。
- 调研:App Store 里含 Rally 的 App 非常多(赛车游戏、信用社、运动);域名全被注册;「来回」中国区也有两款近似 App。商标风险在候选里最高。

### 方案 D:Redpen / 红笔

- 读:red-pen,两个音节。
- 含义:老师批作业的红笔,一看就知道是「批改」;中文「红笔」形象、独一无二,图标也好画。
- 调研:App Store 已有 RedPen 两款(考试题、贴纸),redpen 的 .app/.com/.cn 全被注册;「红笔」中国区有「红笔考典」。

### 方案 E:Margin / 页边

- 读:mar-gin,两个音节。
- 含义:批注写在页边,安静、书卷气,适合「阅读器」这一半。
- 调研:MarginNote(很有名的阅读批注 App)已占住这个词的心智,再加一堆利润计算器;域名全被注册。不建议。

### 方案 F:保留 MDTurn / 加中文名「轮稿」

- 什么都不改,只给中国区加一个中文名。「轮稿」= 一轮一轮改稿。
- 调研:App Store 两区都没有同名;mdturn.app、mdturn.cn 可注册(mdturn.com 已被注册)。
- 代价最低,但英文名的读法问题留着。

## 4. 我的推荐(按调研结果修订)

1. **首选 B:Draftback / 回稿**。英文、中文、.app 域名三样全干净,含义也最准(稿子交出去、改完回到你手上)。
2. **次选 A:Turnpage / 轮稿**。英文干净、延续了 Turn,但 .app/.com 域名被占,中文从「翻篇」换成「轮稿」。
3. 最省事:F,保留 MDTurn,中国区叫「轮稿」。
4. C、D、E 调研后都不建议:同名或近似太多。
